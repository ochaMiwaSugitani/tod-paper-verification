# アルゴリズム実装の妥当性検証

本リポジトリは，論文「頻出医療指示パターン中の経過日数・検査結果を考慮したバリアント抽出とその可視化」（情報処理学会論文誌 TOD）の 4.5.1 節 アルゴリズム実装の妥当性検証 に用いたソースコードおよびテストコードを公開するものです．

## 概要

本研究では，PrefixSpan-py ライブラリを用い，医療指示を `(経過日数, 医療指示種類)` のタプルとしてエンコードすることで，時間間隔を考慮した頻出パターン抽出を実現しています．本リポジトリでは，この実装の妥当性を以下の 2 つの観点で検証します．

- 検証A：PrefixSpan-py との等価性検証
  公開ベンチマークデータ（SPMF Sign）を用いて，本実装（時間を考慮）が PrefixSpan-py のコアロジックを破壊しないことを確認します．
- 検証B：時間間隔処理の動作検証
  手作成 5 名のシーケンスに対して，本実装が手計算による期待値と一致して動作することを確認します．特に経過日数の異なるアイテム（例：`(1, '抗生剤')` と `(2, '抗生剤')`）が正しく区別されることを検証します．

## ファイル構成

| ファイル | 役割 |
|---|---|
| `time_aware_pattern_extractor.py` | ソースコード（本実装）：時間間隔を考慮した頻出パターン抽出関数を提供 |
| `test_verification_a.py` | テストコード（検証A）：SPMF Sign データで PrefixSpan-py との等価性を検証 |
| `test_verification_b.py` | テストコード（検証B）：手作成 5 名のシーケンスで動作検証 |
| `requirements.txt` | 依存ライブラリ |

## 実行環境

- Python 3.8 以降
- prefixspan ライブラリ

## セットアップ

依存ライブラリをインストールします．

```bash
pip install -r requirements.txt
```

## 実行方法

### 検証B（手作成シーケンスでの動作検証）

データの準備が不要なため，すぐに実行できます．

```bash
python test_verification_b.py
```

実行結果は標準出力および `results/verification_b_results.txt` に出力されます．

### 検証A（PrefixSpan-py との等価性検証）

SPMF Sign データセットを事前にダウンロードしてください．

1. SPMF プロジェクトの公式サイトにアクセス：
   <https://www.philippe-fournier-viger.com/spmf/index.php?link=datasets.php>
2. 「Sign」データセットをダウンロード（ファイル名は `Sign.txt` 等）．
3. ダウンロードしたファイルを本リポジトリの `data/Sign.txt` として配置．

その後，以下を実行します．

```bash
python test_verification_a.py
```

実行結果は標準出力および `results/verification_a_results.txt` に出力されます．

## 検証内容

### 検証A：PrefixSpan-py との等価性検証

SPMF Sign データセット（シーケンス数 730，平均シーケンス長 52）を用い，以下 2 つの出力が完全一致するかを検証します．

1. PrefixSpan-py に生のアイテム列を入力した結果
2. 各アイテムを `(0, item)` のタプルとしてエンコードして PrefixSpan-py に入力した結果（時間情報を中立化）

minSup を 100, 200, 300 と変化させ，すべての設定で両者の出力パターン集合が完全一致することを確認します．

### 検証B：時間間隔処理の動作検証

手作成した 5 名の患者シーケンスに対して，本実装の出力が手計算による期待値と完全一致することを確認します．

#### テストデータ

| 患者 | シーケンス |
|---|---|
| 患者1 | `<(0, 手術), (1, 抗生剤), (2, 検査)>` |
| 患者2 | `<(0, 手術), (1, 抗生剤)>` |
| 患者3 | `<(0, 手術), (2, 抗生剤)>` |
| 患者4 | `<(0, 手術), (1, 抗生剤), (2, 検査)>` |
| 患者5 | `<(0, 手術), (1, 検査)>` |

#### 手計算による期待値（minSup = 3）

minSup = 3（5 名中 3 名以上に出現）の条件下で，クローズド頻出パターンは以下の 2 個になります．

- サポート 5：`<(0, 手術)>`
- サポート 3：`<(0, 手術), (1, 抗生剤)>`

#### 検証ポイント

特に，患者3 の `(2, 抗生剤)` と患者5 の `(1, 検査)` が経過日数の異なるアイテムとして正しく区別され，どちらも頻出パターンに含まれないことを検証します．
